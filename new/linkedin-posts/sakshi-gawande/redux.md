## 𝗨𝗻𝗱𝗲𝗿𝘀𝘁𝗮𝗻𝗱𝗶𝗻𝗴 𝗥𝗲𝗱𝘂𝘅 𝗱𝗼𝗲𝘀𝗻’𝘁 𝗵𝗮𝘃𝗲 𝘁𝗼 𝗯𝗲 𝗰𝗼𝗺𝗽𝗹𝗶𝗰𝗮𝘁𝗲𝗱.

Think of Redux like a banking system:

- The store is your bank account.
- Actions are the deposit or withdrawal requests.
- Reducers process those requests and update the balance.
- Dispatch submits the request to be processed

𝗥𝗲𝗱𝘂𝘅 𝗳𝗼𝗹𝗹𝗼𝘄𝘀 𝗮 𝘂𝗻𝗶𝗱𝗶𝗿𝗲𝗰𝘁𝗶𝗼𝗻𝗮𝗹 𝗱𝗮𝘁𝗮 𝗳𝗹𝗼𝘄, meaning state changes in one direction and updates the UI accordingly.

The Core Concepts of Redux:

- 𝗦𝘁𝗼𝗿𝗲: A centralised place where all the application's state is stored.
- 𝗔𝗰𝘁𝗶𝗼𝗻𝘀: Simple objects that describe what should happen (e.g., increment a counter, fetch data).
- 𝗥𝗲𝗱𝘂𝗰𝗲𝗿𝘀: Pure functions that take the current state and an action, then return a new state.
- 𝗗𝗶𝘀𝗽𝗮𝘁𝗰𝗵: A function used to send an action to the reducer and trigger a state update.
- 𝗦𝗲𝗹𝗲𝗰𝘁𝗼𝗿𝘀: Functions that extract specific pieces of state from the store to use in components.

Redux helps keep state organized, predictable, and scalable.
