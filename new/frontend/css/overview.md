### Types of css properties

- CSS variables
- Utility classes
  - always have only 1 property & which can be reusable across various elements
- Component classes

- translateZ()

  - Z is -ve Backwards
  - Z is +ve Forward

- translateX()

  - X is -ve towards left
  - X is +ve towards right

- translateY()

  - Y is -ve Upwards
  - Y is +ve Downwards

- scaleX()
  - by default the value is 1
  - scaleX(2) increase by 2 times on X axis
